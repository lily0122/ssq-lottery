# 双色球选号实验室 V1.0

一个可在 Windows 本地运行的 Streamlit 学习项目。每期 A–E 五种策略各生成5注（策略内部不重复），附特征、评分、理由；支持数据导入、冷热遗漏分析、严格顺序回测和复现记录。

**历史模式不会提高下一期的理论中奖概率。每个合法组合一等奖概率同为 1/17,721,088。分数不是概率，不承诺预测优势。**

## Windows 快速开始

1. 安装 Python 3.11 或更新版本（建议3.12/3.13），安装时勾选 Python Launcher 和 Add Python to PATH。
2. 解压项目，双击 `setup.bat`。需要联网下载依赖，首次安装可能需要几分钟。
3. 安装完成后双击 `run.bat`，浏览器将打开 http://localhost:8501 。保持启动窗口开启；关闭程序可在该窗口按 Ctrl+C。
4. 默认读取附带的**官方历史数据**；也可切换到明确标记的模拟演示，可以立即查看分析、生成25注和运行小规模回测。

也可以在项目目录的 PowerShell 中运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

无需激活虚拟环境，因此不需要修改 PowerShell 执行策略。若没有 `py` 命令，可将第一行的 `py -3` 改为 `python`。若端口被占用，在最后一行加 `--server.port 8502`。

## 真实历史数据与来源

本项目已附带从中国福彩官方接口取得并校验的 **2086期真实记录：2013001（2013-01-01）至2026128（2026-11-08）**。采集时间为2026-11-10，21页原始响应与来源清单一并保留。接口在请求2003年起的数据时仍仅返回2013年起记录；**2003–2012未获取，不能称为全历史**。未补造任何缺失开奖记录。

官方往期开奖公告入口：https://www.cwl.gov.cn/ygkj/wqkjgg/ 。程序尝试使用该站公开查询接口，从2003-02-16分页读取到当前日期：

```powershell
.\.venv\Scripts\python.exe fetch_official.py
```

成功后生成 `data/official.csv`、同名 `.provenance.json` 和 `data/raw_时间/` 原始响应。界面切换到“本地官方采集文件”。保留抓取URL、时间、响应哈希及规范CSV哈希。网络、访问限制、接口字段变化、重复分页或验证失败会明确报错，不使用替代数据。采集器只是尽力读取接口全部返回页，不保证接口具有全历史覆盖；不可绕过网站访问控制。采集失败可手工从可靠来源整理CSV。

CSV 路径：界面选择“导入CSV”，下载空模板 `data/import_template.csv`，填好后上传。采用 UTF-8 / UTF-8 BOM；列为：

```text
issue,date,red_1,red_2,red_3,red_4,red_5,red_6,blue,source
```

`issue` 为7位期号，日期为 `YYYY-MM-DD`，6个不同红球1–33、蓝球1–16；`source` 必填原始公告URL或可信文件出处。模板故意不附号码示例，避免误作真实记录。上传文件仅在会话内使用，可下载校验后CSV保存。未提供自动合并，冲突需用户核实后重新导入。

校验拒绝空值、非整数、重复或冲突期号/日期、无效日期、未来日期、年份不符、号码越界/红球重复。红球自动排序，记录按日期排序；检测每年范围内/年初序号缺口并提示，绝不补造。跨年年末缺期和查询范围之外缺期不能自动证明；来源字段本身也不证明真实性。缺期时“上期”实际指已导入的前一条记录，遗漏是已观察记录数。模拟模式使用固定种子生成180条假数据，明确标记 `SYNTHETIC_DEMO_NOT_REAL`，日期亦非真实开奖日历。

## 使用与算法

侧栏可设置截止期、短期（默认30期）、长期（0表示全部已知历史）、种子、候选池及E权重。短期不大于非零长期；历史不足窗口时使用可用记录，不读取未来。选号池默认10万，可调小以加快速度。

- **A 均匀随机**：独立随机流从33选6、16选1，拒绝重复直到5注；不参与分数排序。其输出不受候选池大小影响。
- **B 结构**：六项等权。奇数个数、三区分布使用精确组合类别质量相对最大类别质量；和值、跨度、连号对数、质数个数使用明确高斯形状偏好，中心分别102、24、1、2，尺度30、8、1.5、2。三区为1–11/12–22/23–33。蓝球没有人为的均衡偏好。
- **C 频率遗漏**：红蓝各自计算长期和短期出现频率的平均排名（并列平均排名/号码数），以及 min(当前遗漏,30)/30，三项等权；红球6个号码平均后权重75%，蓝球25%。偏好热号与大遗漏仅是实验假设，不代表“该出了”。未出现号码的遗漏为样本长度，只是下界。
- **D 期际**：长期窗口内相邻记录的重复红球数0–6分布，加一平滑并除最大类别次数；蓝球使用“上次蓝球→下一蓝球”的16分类计数行，加一平滑并除最大计数。红75%/蓝25%。没有观察到相关转移时平滑给出中性分，不宣称关系有效。
- **E 综合**：B/C/D加权平均，默认0.35/0.35/0.30，非负权重自动归一化。无自动调参。

B–E共用一批均匀采样后去重的候选池，各取评分前5注。并列按完整号码字典序；这会形成可见偏好，未来可改随机打破并列。结构类别质量不是某一注的中奖概率。各项分数范围0–100，A排序分留空但同样展示描述性特征。不同策略之间允许重合并显示重合数。

生成后下载CSV与JSON：含全部票、各项分数、理由、算法版本、窗口/池大小/权重/种子、数据截止期日期、规范数据SHA256、来源及NumPy/Pandas版本。复现需保留同一规范数据、参数及软件版本。新数据导入或参数改变后旧结果自动隐藏。

## 回测与解读

默认训练至少50期，评估最近30期，每步使用严格的 `data[:目标索引]` 前缀重新计算特征，然后生成5注，再与目标期比较。种子由基础种子和目标索引派生，逐注记录。默认回测候选池1000以控制耗时，可调至10万；回测参数和截止数据哈希单独导出。大池和长历史会较慢。

A是同样5注的随机基准；报告逐注红/蓝命中、标准奖级、各奖级次数、相对A平均红球命中差。每注理论平均红球命中36/33，蓝球命中率1/16。只按奖级规则计算，不包含奖金、派奖或收益率。每期5注之间以及同期开奖的策略结果相关；不将这些相关样本当作独立证据。单次基准、小样本的偶然差异不证明优势，未提供显著性检验。看过回测再调权重属于探索，不能把同段结果当独立验证。

## MVP 限制与后续

使用CSV而非数据库，保持本地项目简单；不提供自动数据更新、用户账户或投注购买。官方接口可能受网络或结构变化影响；已附带数据可离线使用，2003–2012仍需可靠来源补全。后续可加入第二官方来源核对、明确缺期清单、多随机种子回测及独立留出段评估。依赖采用主要版本范围；要精确锁定本机复现环境，可运行 `python -m pip freeze > environment-lock.txt` 并保存该文件。
